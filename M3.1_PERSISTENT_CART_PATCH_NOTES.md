# NaijaBites M3.1 — Persistent Cart Patch

This patch is built on the current V006 React/Vite + Express + MySQL project archive (`naijabites(1).zip`). It does not replace the project and does not include or modify `.env`.

## Included

- `server/migrations/V007__persistent_cart.up.sql` and `.down.sql`
- Authenticated customer cart API under `/api/v1/me/cart`
- Cart service with transactional add/update operations, current product/vendor visibility checks, stock/max-per-order validation, and integer-kobo totals
- React Query cart hooks, cart page, cart count in the top bar, and product-modal Add to Cart action
- Cart request-schema tests

## Database safety

The V007 migration is included but has NOT been applied. V001–V006 are unchanged. Back up the database before applying V007. Do not run the rollback migration as a routine operation; cart data would be removed.

## Apply

1. Back up the `naijabites` MySQL database.
2. Extract this patch into the project root, preserving the existing `.env`.
3. Run `npm ci` if dependencies are not installed.
4. Run `npm test` and `npm run build`.
5. Run `npm run db:status` and confirm V001–V006 are applied and V007 is pending.
6. Only after reviewing the backup and status, run `npm run db:migrate` to apply V007.
7. Restart the backend and frontend, sign in using a customer account, and test adding/removing/updating cart items.

The checkout button is intentionally disabled; checkout/address management belongs to M3.2.

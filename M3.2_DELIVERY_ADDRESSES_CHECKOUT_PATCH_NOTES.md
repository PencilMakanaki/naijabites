# NaijaBites M3.2 patch — delivery addresses and checkout preview

Apply this patch over the current NaijaBites project after the M3.1 persistent-cart patch is installed and V007 is applied.

## Included
- V008 customer delivery-address table (up/down migrations).
- Customer-only address CRUD and default-address API.
- Read-only checkout summary API (cart, saved addresses, configured delivery fee, blockers).
- Customer address-management page and checkout-preview page.
- Cart-to-checkout navigation and account address-management link.
- Address schema tests.

## Safety
- V008 is intentionally NOT applied by this patch. Run `npm run db:status` first; V008 should show `pending`.
- Do not run migrations until the code patch is installed and the user approves the migration.
- Checkout is a preview only. It does not create orders, reserve stock, or initiate payments.
- The delivery fee remains blocked until `delivery_fee_flat_kobo` is configured in platform settings.
- No `.env`, database backup, credentials, or node_modules are included.

## Apply
Extract the ZIP into the existing NaijaBites project root and allow replacement of the listed existing files. Then run `npm test` and `npm run build` once for this new milestone. Do not repeat the completed M3.1 checks.
